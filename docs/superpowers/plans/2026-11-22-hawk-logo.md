# Hawk Logo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the three-candy logo and browser-tab icon with the approved hawk head holding a plain raspberry sale tag.

**Architecture:** The logo stays an inline SVG in `tarjoushaukka/static/index.html` (`<svg class="logo" id="logo">`), drawn with the page's colour tokens so it follows dark mode. It has two animated groups: the hawk (head, beak, eye, brow) and the tag, which is drawn between the head and the beak so the beak covers its top. The favicon is the same drawing as a data-URI SVG in fixed light-mode colours.

**Tech Stack:** Plain HTML/CSS/SVG in one static page; Flask serves it; pytest for the served-page check.

**Spec:** `docs/superpowers/specs/2026-11-22-hawk-logo-design.md`

## Global Constraints

- Colours: head `var(--ink)`, beak `var(--lemon)`, brow and tag `var(--raspberry)`, tag hole `var(--paper)`, eye white `#fff` with plum `#2a1630` ring and pupil (fixed, so the eye reads on the light dark-mode head).
- Favicon: fixed light colours `#2A1630`, `#FFD84A`, `#D91A5B`, `#F6F2F7`, `#FFFFFF`.
- Geometry: the approved mockup's paths, unchanged. Head and beak are drawn inside `transform="translate(0 1) scale(.88)"`; the tag inside `transform="translate(19.6 15.4) rotate(-30)"`.
- Reduced motion: no logo animation when `prefers-reduced-motion: reduce`.
- The `.logo.busy` class (toggled in `render()`) stays the "checking" hook.

## Review Focus

- Dark mode: the head turns light (`--ink`); the eye, beak and tag must stay visible on it and on the dark background.
- 16 px browser tab: the hawk and tag must still read as a bird with a tag, not a blob.
- Reduced motion: the tag must not sway while a check runs.
- A long check: the busy sway loops smoothly with no jump between cycles.
- Stale cache: nothing else in the page references the removed candy shapes (`ellipse`, `rect` in `#logo`).

The served-page test in Task 1 pins the markup; the screenshots in Task 1 Step 5 cover dark mode, 16 px and the busy state.

- [ ] **Step 3: Replace the logo SVG and favicon**

A CSS animation on a group replaces that group's `transform` attribute, so each animated group wraps an inner group that carries the positioning transform. Logo, in this order (back to front):

1. `<g class="hawk"><g transform="translate(0 1) scale(.88)">` head `</g></g>`
2. `<g transform="translate(19.6 15.4) rotate(-30)"><g class="tag">` tag and hole `</g></g>`
3. `<g class="hawk"><g transform="translate(0 1) scale(.88)">` beak, eye, brow `</g></g>`

Paths from the spec's mockup:

- Head: `M3 29 C3.5 18 7 9 15 7 C19.5 6 23.5 7.2 25.5 10 L19 14 C17.5 21 12.5 26.8 3 29 Z`
- Beak: `M18.8 9.6 C23.6 8.4 27.6 10.6 28.1 15 C28.3 17.6 27.4 19.8 25.8 21.4 C25.9 19.2 24.9 17.7 23.2 17.5 L19.3 17.6 C18.5 15 18.2 12 18.8 9.6 Z`
- Eye: circle `cx=15.2 cy=12.2 r=2.4` (white, plum stroke .8) and pupil `cx=15.8 cy=12.2 r=1.2`
- Brow: `M11.4 8.8 L19.4 11`, stroke width 2.2, round caps
- Tag: `M0 0 L4.3 3.3 L4.3 11.2 Q4.3 12.4 3.1 12.4 L-3.1 12.4 Q-4.3 12.4 -4.3 11.2 L-4.3 3.3 Z`, hole circle `cx=0 cy=4.6 r=1.1`

Favicon: the same shapes as a URL-encoded data-URI SVG with the fixed colours from Global Constraints.

- [ ] **Step 4: Replace the logo motion CSS**

- `.logo .hawk`: the existing `drop` keyframes on load.
